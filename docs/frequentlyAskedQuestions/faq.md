1. What needs to be submitted for each milestone?
For each milestone, submissions should consist of:
    - README
    - Project Log
    - Project Poster
    - Project Video

The README should consist of:
- your level of achievement, project scope (one sentence
version and a longer descriptive version), as well as
- Milestone 1 (Ideation): include problem motivation, proposed core
features / user stories, design and plan
- Milestone 2 (Prototype): include core features developed, problems
encountered
- Milestone 3 (Extension): include bugs squashed, edge features
developed, problems encountered, and user testing
… and any other info that justify your LoA!
- Note: The README should incorporate all (but possibly
condensed) information from a previous one

The Project Log should consist of:
- What were the tasks performed by each member?
- When were the task performed?
- How many hours were spent in completing each task?
(Note: The total number of hours spent for each member should
be at least 140 hours at the end of the programme.)

The Project Poster and Video should consist of:
- Milestone 1: Showcase your formulated project idea and
technical proof of concept
- Similar to Liftoff submissions but more details
required.
- Milestone 2 & 3: Showcase your prototype / complete
system
- Poster: A1 size, multi-panel / segment
- Video: ~5 minutes

2. Are teams allowed to use AI tools for coding / milestone submissions?
You are NOT allowed to use AI tools to generate codes for your project or content for your Milestone submissions.
However, you are allowed to use AI tools to
- self-learn (e.g., to understand what is CI/CD)
- integrate with them for your features (e.g., to call
ChatGPT API get answers on behalf of the users)
- generate assets for your project (e.g., portrait
images for the characters in your game) 16

3. Is it possible to participate in Orbital individually instead of forming a team of two?
Unfortunately, this is not allowed since it violates the learning objectives of the programme.
Please consider finding a partner or doing your own project outside Orbital. Thank you.

4. Is it possible for students who do not fulfil the prerequisites to join Orbital and participate without earning credits?
Both students in a team must be officially registered under orbital to take part. 
In addition, if a team member fails to contribute, the whole team will be removed and the member causing the problem will be given a CU grade under CP2106.

5. Will having an SOC student in the team to increase the chance of getting selected for Orbital?
Teams with at least one year one SoC student will have a higher chance of being accepted.
